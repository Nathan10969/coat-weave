Table recovery rules:
- If an image is attached, treat the image as the source of truth. The HTML is
  only a noisy OCR draft.
- If no image is attached, use the HTML only and set confidence accordingly.
- Preserve multi-level headers, merged cells, footnotes, units, blanks, dashes,
  zeros, ranges, inequality signs, and non-numeric ratings exactly as visible.
- Do not normalize 0, blank, dash, "ND", "<0.1", "about 5", "5-10", or "5 : 1"
  into the same value.
- Put a corrected HTML table in corrected_table_html when you can represent the
  visible structure. If HTML is too risky, set corrected_table_html to null and
  provide table_markdown_exact instead.
- Record every material image-vs-HTML conflict in html_conflict_notes.
- ocr_confidence reflects table recovery only. It is not fact-extraction
  confidence.

Coating table semantics:
- Formulation tables: preserve component names, sample columns, amounts, units,
  parts/wt%/phr/solids basis, totals, and blank/dash/zero meaning.
- Performance tables: preserve test/property names, result values, units, test
  standards, rating scales, and sample binding. Rows such as Surface (film),
  Surface (metal), and ratings 1-6 are evaluation-result rows when they report
  coating performance.
- Condition tables: preserve temperature, time, pressure, pH, solids, mixing,
  drying, curing, and measurement conditions.
- Structure/reaction tables: recover visible labels and substituent tables, but
  do not fabricate exact SMILES/formulae from partial or generic structures.
- Use the exact English closed set for table_subject. Legacy labels such as
  "performance comparison" should be normalized to "performance_comparison",
  "test condition" to "test_condition", and "structure/reaction" to
  "structure_or_scheme".

Polarity decision rules:
- "negative" if the row label contains "Comp", "Comparative", "Reference",
  "Vergleich", "comparison", or similar comparative-control wording.
- "positive" if it contains "Example", "Embodiment", "Inventive", "Beispiel",
  or similar inventive-example wording.
- otherwise "unknown".
